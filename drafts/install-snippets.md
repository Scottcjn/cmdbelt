## One-line Claude Code hook install

```sh
pipx install cmdbelt && cmdbelt install claude-code
```

That prints the `PreToolUse` snippet to merge into `~/.claude/settings.json` (or project
`.claude/settings.json`). cmdbelt never edits the file for you. The snippet, for reference:

```json
{"hooks": {"PreToolUse": [{"matcher": "Bash",
  "hooks": [{"type": "command", "command": "$(command -v cmdbelt) hook claude-code", "timeout": 120}]}]}}
```

Verify it's wired:

```sh
echo '{"tool_name":"Bash","tool_input":{"command":"rm -rf /"}}' | cmdbelt hook claude-code; echo exit=$?
# exit=2 with the rule reason on stderr = working.
```

Contract: deny → exit 2 + reason on stderr (Claude sees it); ask → JSON `permissionDecision:"ask"`;
allow → silent (your own Claude Code permission rules still apply; cmdbelt never auto-approves).

## Documented Codex CLI wiring

Codex needs two pieces, because a Codex `PreToolUse` hook **cannot return "ask"** (Codex treats an
ask as a failed hook and continues). So the hook enforces allow/deny, and a generated Starlark
rules file carries the real prompts.

**1. The hook** (`~/.codex/hooks.json` for user scope, or `<repo>/.codex/hooks.json` for project):

```sh
cmdbelt install codex > ~/.codex/hooks.json
# then run  /hooks  inside Codex to review and trust it.
```

It registers both `PreToolUse` (allow/deny; `ask`→deny by default) and `PermissionRequest`
(`cmdbelt hook codex --event PermissionRequest`). Hooks are on by default; `[features] hooks = false`
in Codex config disables them.

**2. The prompt rules** (so risky-but-allowed commands prompt instead of hard-deny):

```sh
cmdbelt install codex --rules > ~/.codex/rules/cmdbelt.rules
codex execpolicy check --rules ~/.codex/rules/cmdbelt.rules -- docker system prune   # sanity check
```

Only the prefix-expressible rules (e.g. `shred`, `git stash drop`, `git reflog expire`) appear in
the rules file; flag/path/pipe-based rules (`rm -rf /`, `curl | sh`, `git push --force main`) are
enforced by the hook. This split is documented in [docs/INTEGRATIONS.md](../docs/INTEGRATIONS.md).

## Any other agent (one line)

```sh
cmdbelt exec -- <command>     # check → snapshot → run → propagate exit code
```
